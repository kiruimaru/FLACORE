# Папка тем

Здесь лежат примеры своих тем и документация формата. Приложение читает свои
темы не отсюда, а из папки профиля (`%APPDATA%\FLACORE\FLACORE\themes` на
Windows) — её открывает кнопка **Оформление → Тема → Открыть папку тем**.

## Как поставить тему из этой папки

1. Скопируйте папку темы (например `example`) в папку профиля.
2. В приложении откройте **Оформление → Тема** — тема появится карточкой,
   щёлкните её, чтобы применить.

Либо в приложении: **Оформление → Тема → Установить тему…** и выберите
`theme.json` — папка скопируется сама.

## Что внутри темы

```
themes/example/
  theme.json   метаданные, цвета, шрифт, токены
  theme.qss    свои правила поверх базовых стилей (необязательно)
  assets/      картинки и шрифты для theme.qss (необязательно)
```

Полное описание полей, токенов и хуков — в [docs/THEMES.md](../docs/THEMES.md).
