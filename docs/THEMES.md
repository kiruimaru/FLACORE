# Темы FLACORE

Тема — это папка. Внутри `theme.json` с метаданными и цветами, необязательный
`theme.qss` со своими правилами и необязательная папка `assets/` с картинками.
Формат один в один как у каталога тем SoundCloud Desktop, поэтому темы легко
переносить и писать руками в блокноте.

```
themes/<id>/
  theme.json     метаданные и токены
  theme.qss      необязательно: свои правила поверх базовых стилей
  preview.webp   необязательно: картинка для карточки темы
  assets/        необязательно: картинки и шрифты для theme.qss
```

Встроенные темы лежат внутри программы (их нельзя удалить, но можно выгрузить
и править копию). Свои темы приложение ищет в папке профиля:

```
Windows: %APPDATA%\FLACORE\FLACORE\themes
Linux:   ~/.local/share/FLACORE/FLACORE/themes
macOS:   ~/Library/Application Support/FLACORE/FLACORE/themes
```

Точный путь всегда виден на странице **Оформление → Тема**, кнопка
**Открыть папку тем** открывает её в проводнике.

## Как поставить свою тему

1. **Оформление → Тема → Установить тему…** и выбрать `theme.json`
   (или папку с ним) — тема скопируется в папку профиля.
2. Либо просто скопировать папку темы в папку профиля и нажать в приложении
   **Оформление → Тема** (список обновится) — тема появится карточкой.
3. Либо начать с готовой: **Экспорт текущей…** выгрузит активную тему файлами,
   правьте и ставьте обратно.

## theme.json

```json
{
  "id": "midnight",
  "name": "Midnight",
  "description": { "ru": "Глубокий синий, холодное стекло", "en": "Deep blue, cool glass" },
  "version": "1.0.0",
  "author": { "name": "Ваше имя", "github": "логин" },
  "license": "MIT",
  "accent": "#7aa2ff",
  "background": "#070a12",
  "font": "inter",
  "mode": "beauty",
  "tokens": { "radius": 18, "glass-alpha": 0.5, "blur": 30 }
}
```

| Поле | Обязательное | Значения |
|---|---|---|
| `id` | да | 3–32 символа: `a-z`, `0-9`, `-`; без пробелов, `tools` занято |
| `name` | да | до 32 символов |
| `description` | да | объект с `ru` и/или `en`, до 140 символов |
| `version` | нет | `1.0.0` по умолчанию |
| `author` | да | `author.name` обязателен, `author.github` необязателен |
| `license` | нет | по умолчанию MIT |
| `accent` | нет | `#rrggbb` — акцент интерфейса |
| `background` | нет | `#rrggbb` — базовый фон окна |
| `font` | нет | `segui`, `inter`, `manrope`, `onest`, `golos`, `montserrat`, `rubik`, `nunito`, `raleway`, `comfortaa`, `system` |
| `mode` | нет | `beauty` (всё включено), `medium` (меньше размытия), `light` (без размытия и анимаций) |
| `tokens` | нет | любые токены из таблицы ниже |

Если шрифта нет в системе, берётся системный — интерфейс не сломается.

## Токены

Цвета, которых нет в `theme.json`, выводятся из `accent` и `background`:

| Токен | Что это | Откуда берётся |
|---|---|---|
| `accent`, `accent-hover`, `accent-glow`, `accent-soft`, `accent-contrast` | акцент, наведение, свечение, мягкая заливка, текст поверх акцента | из `accent` |
| `bg-primary`, `bg-elevated` | фон окна и приподнятые поверхности | из `background` |
| `panel`, `panel-strong`, `panel-solid` | полупрозрачные панели («стекло») | из `background`, светлая/тёмная автоматически |
| `border`, `border-strong` | рамки обычная и акцентная | из `background`/`accent` |
| `text`, `text-muted`, `text-faint` | основной, второстепенный и самый тихий текст | из яркости фона |
| `hover-bg`, `sel-bg`, `shadow` | подсветка наведения, выделение, тень | из `background`/`accent` |
| `danger`, `success` | ошибка и успех | константы |

Геометрия и шрифт: `radius`, `radius-sm`, `radius-lg`, `font-size`,
`font-size-sm`, `font-size-lg`, `font-sans`, `blur`, `glass-alpha`, `bg-blur`,
`bg-image`, `animations`, `titlebar-height`, `sidebar-width`.

Любой из этих токенов можно переопределить в `tokens` — тогда он берётся как
есть, а не выводится. Цвета принимаются как `#rrggbb` или `#aarrggbb`
(альфа первая, как читает Qt).

## theme.qss — свои правила

Пишется как обычный CSS (это QSS от Qt). Вместо переменных используются токены
с `@` — приложение подставляет их значения:

```css
QWidget[dataUi="player"] {
    border: 1px solid @border-strong;
    background: qlineargradient(x1:0, y1:0, x2:1, y2:1,
        stop:0 @panel, stop:1 @accent-soft);
}

QPushButton[variant="accent"] {
    border-radius: 14px;
    color: @accent-contrast;
    background: @accent;
}
```

Стабильные хуки (не зависят от вёрстки и версии):

| Селектор | Элемент |
|---|---|
| `QWidget[dataUi="app"]` | всё окно (фон, градиенты) |
| `QWidget[dataUi="titlebar"]` | шапка с поиском и кнопками окна |
| `QWidget[dataUi="sidebar"]` | левая панель разделов |
| `QListWidget[dataUi="sidebar"]::item` | пункт меню |
| `QLineEdit[dataUi="search"]` | поле поиска |
| `QWidget[dataUi="main"]` | страницы по центру |
| `QWidget[dataUi="player"]` | плавающая панель плеера |
| `QWidget[dataUi="card"]` | карточка настроек |
| `QListWidget[dataUi="trackList"]` | список треков |
| `QListWidget[dataUi="results"]` | результаты поиска |
| `QLabel[dataUi="toast"]` | всплывающее сообщение |
| `QPlainTextEdit[dataUi="cssEditor"]` | редактор своего CSS |
| `QPushButton[dataUi="themeTile"]` | карточка темы |
| `QPushButton[dataUi="transport"]`, `"transportMain"`, `"windowButton"` | кнопки транспорта и окна |
| `QPushButton[variant="accent" \| "ghost" \| "danger"]` | три вида кнопок |

Что вырезается при загрузке (с сообщением в приложении):

- `@import` и любые `url(http…)`/`url(//…)` — тема не может тянуть файлы из сети;
- `behavior:` — как в старых IE;
- всё, что длиннее 256 КБ.

`url("assets/картинка.png")` превращается в абсолютный путь внутри папки темы —
локальные картинки и шрифты работают без сетевых ссылок.

## Свой CSS в настройках

**Оформление → Свой CSS** — то же самое, но без установки темы: правила
ложатся поверх активной темы, применяются через 0,7 секунды после правки и
запоминаются. Переключатель в карточке выключает стили, не удаляя текст.

Если стиль сломал интерфейс:

- **Ctrl+Alt+Shift+C** — выключает свой CSS и тему, повторное нажатие возвращает;
- либо запуск с флагом `--no-custom-css`: приложение стартует в безопасном виде.

## Режимы производительности

| Режим | Что делает |
|---|---|
| `beauty` | полное размытие стекла и фона, анимации пятен акцента |
| `medium` | размытие урезано, анимации остаются |
| `light` | без размытия и анимаций — для слабых машин |

Тот же режим можно задать в `theme.json` полем `mode` и переопределить в
настройках: настройки пользователя главнее темы.

## Акцент из обложки

**Оформление → Акцент → «Брать акцент из обложки трека»**: когда у трека есть
вшитая обложка, акцент интерфейса пересчитывается по её цветам (алгоритм
отбирает насыщенный, но не вырожденный оттенок). Тема при этом остаётся.

## Готовые примеры

- `themes/example/` в репозитории — минимальная пользовательская тема для копирования.
- **Экспорт текущей…** — выгружает любую встроенную тему (`liquid-glass`,
  `midnight`, `carbon`, `sugar-cloud`, `neon`) файлами, чтобы править её как свою.
